# Weather Forecasting

A Python command-line tool that shows the current temperature of any city using the Open-Meteo API.

## Features
- Converts country name to country code (pycountry)
- Finds city coordinates (Open-Meteo Geocoding API)
- Displays current temperature

## Setup
pip install -r requirements.txt
python api.py

## Usage
Enter the country name and city name when prompted.
